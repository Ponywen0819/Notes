# 題目

給定陣列 `nums` 與目標值 `target`，計算有多少個**子陣列**中 `target` 是**多數元素**（出現次數 > 子陣列長度的一半）。
本題是 3737 (Majority Element I) 的加強版，資料量更大，$O(n^2)$ 會 TLE。

# 核心轉換：把「多數」變成「前綴和 > 0」

把陣列做轉換：等於 `target` 的元素記為 `+1`，其餘記為 `−1`。

那麼在子陣列 `nums[l..r]` 中，`target` 是多數
$\iff$ `target` 出現次數 > 其他元素次數
$\iff$ 轉換後的子陣列總和 **> 0**。

設轉換後的[[前綴和 (Prefix Sum)|前綴和]]陣列為 $s$（長度 $n+1$，$s[0]=0$），則子陣列 `nums[l..r]` 的轉換和為：
$$s[r+1] - s[l]$$

條件 $s[r+1] - s[l] > 0$ 等價於：
$$s[l] < s[r+1]$$

**問題轉化為**：對每個 $r$，計算有多少個 $l$（$0 \le l \le r$）滿足 $s[l] < s[r+1]$。

# 為什麼可以 O(1) 維護

直接對每個 $r$ 掃所有 $l$ 是 $O(n^2)$。優化關鍵有兩點：

1. **值域有限**：每個前綴和都落在 $[-n, n]$。用計數陣列 `pre[v]` 記錄「值為 $v$ 的前綴和出現過幾次」。對當前 $s[r+1]$，合法 $l$ 的數量 = `pre` 中所有 `v < s[r+1]` 的總和（也就是 `pre` 的前綴和）。

2. **每步只變動 ±1**：相鄰位置的前綴和只差 `+1` 或 `−1`，所以「查詢上界」也只移動一格。用變數 `presum` 增量維護「目前 `v < cnt` 的累計次數」，每步 $O(1)$：
   - 當前轉換值為 `+1`：$s[r+1] = s[r]+1$，查詢範圍**擴大一格** → `presum += pre[s[r]]`。
   - 當前轉換值為 `−1`：$s[r+1] = s[r]−1$，查詢範圍**縮小一格** → `presum -= pre[s[r+1]]`。

更新完 `presum` 後，把當前前綴和記入 `pre`，並把 `presum` 加進答案。

> 由於前綴和可能為負、而陣列不能用負索引，所有值存進 `pre` 時都**平移 $n$**（即 `pre[v + n]`）。

# 實作 (C++)

`cnt` 直接存「已平移 $+n$ 的前綴和」（初始 `n` 代表 $s=0$），索引就不必再額外加 `n`。

```cpp
class Solution {
public:
    long long countMajoritySubarrays(vector<int>& nums, int target) {
        int n = nums.size();
        // pre[v] 記錄前綴和 = v-n 的出現次數，索引平移 n，範圍 [0, 2n]
        vector<int> pre(n * 2 + 1, 0);
        pre[n] = 1;                  // s[0] = 0（平移後是 n）
        int cnt = n;                 // 目前前綴和（已平移）
        long long ans = 0, presum = 0;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == target) { // +1：範圍擴大，先加入舊的 pre[cnt]
                presum += pre[cnt];
                ++cnt;
                ++pre[cnt];          // 記錄當前前綴和
            } else {                 // -1：範圍縮小，減去新的 pre[cnt]
                --cnt;
                presum -= pre[cnt];
                ++pre[cnt];
            }
            ans += presum;           // 累計合法 l 的數量
        }
        return ans;
    }
};
```

> 細節：`+1` 時是「先用舊範圍累加 `pre[cnt]`、再 `++cnt`」；`−1` 時是「先 `--cnt`、再減去新範圍的 `pre[cnt]`」。兩者都對應「查詢上界 $s[r+1]$（嚴格小於）」邊界剛好移動一格，且當前位置自己不被算進合法 $l$。

# 複雜度

- 時間：$O(n)$ — 每個元素只做常數次操作。
- 空間：$O(n)$ — 計數陣列 `pre` 大小 $2n+1$。

# 重點整理

- **+1 / −1 轉換**是處理「多數元素 / 出現次數比較」類問題的常用手法。
- 「子陣列總和 > 0」⇒ 前綴和差 ⇒ 變成統計 $s[l] < s[r+1]$ 的配對數。
- 相鄰前綴和只差 ±1，是能把 $O(n^2)$ 降到 $O(n)$ 的關鍵；否則就要用[[前綴和 (Prefix Sum)|樹狀數組]]做有序計數，會多一個 $\log n$。
- 負索引一律**平移**處理。
