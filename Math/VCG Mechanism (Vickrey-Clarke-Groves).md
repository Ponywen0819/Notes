# 動機:為什麼「贏家付自己出的價」會出問題

在拍賣 / 資源分配問題中,每個參與者對「贏得某個結果」有一個只有自己知道的**私有價值** $v_i$。最直覺的規則是「贏家付自己出的價」(pay-as-bid):但這樣一來,理性的參與者不會誠實出價——出價等於真實價值只會讓自己利潤壓到 0,所以每個人都有誘因**壓低出價**(bid shading)。壓多少沒有一個穩定答案,因為最優出價依賴於「猜對手會出多少」,整個機制因此難以分析、也難以保證效率。

**VCG 機制(Vickrey–Clarke–Groves)** 的目標:設計一套分配 + 付款規則,讓「誠實回報自己的真實價值/成本」變成每個參與者的**顯性策略(dominant strategy)**——不論別人怎麼出價,誠實對自己都最好。這組結果由三篇經典論文接力完成:Vickrey (1961) 的單品第二價拍賣、Clarke (1971) 的 pivot rule、Groves (1973) 的一般化。

# 特例:Vickrey 第二價拍賣

單一物品,$n$ 個買家,買家 $i$ 對物品的價值是 $v_i$(私有)。規則:

- 出價最高者得標。
- **得標者付的不是自己的出價,而是第二高的出價。**

> 直覺:得標者的付款完全不受自己出價高低影響(只要還是最高就好),所以**出低會冒著沒得標的風險,出高完全沒有額外好處**——唯一不會讓自己變差的策略就是誠實出價 $b_i=v_i$。這是 VCG 家族「誠實是顯性策略」性質最容易理解的原型。

# 一般化:VCG 機制

VCG 把「第二價拍賣」的精神推廣到**任意分配問題**(不只單品拍賣,也包括多物品組合、任務分配、資源排程……)。設:

- 可行結果集合 $\mathcal{X}$(例如:把任務分給哪個 agent、把哪些物品分給誰)。
- 每個參與者 $i$ 對每個結果 $x\in\mathcal{X}$ 申報一個價值 $\hat v_i(x)$。

**第一步:選出最大化「申報總價值」的結果**

$$x^*=\arg\max_{x\in\mathcal{X}}\sum_{i}\hat v_i(x)$$

**第二步:每個參與者付出他對其他人造成的「外部性(externality)」——即 Clarke pivot 付款**

$$p_i = \underbrace{\max_{x\in\mathcal{X}}\sum_{j\neq i}\hat v_j(x)}_{\text{沒有我時,其他人能達到的最大總價值}} \;-\; \underbrace{\sum_{j\neq i}\hat v_j(x^*)}_{\text{我在場時,其他人在 }x^*\text{ 實際拿到的價值}}$$

> 直覺:你要付的錢,剛好等於「你的存在讓其他所有人一共損失了多少」。如果你根本不影響結果(你退出,最優結果對其他人一樣好),你就不用付錢。這正是**你造成的邊際外部成本**——不多不少。

**為什麼誠實回報是顯性策略?** 因為每個參與者的效用是

$$u_i = v_i(x^*) - p_i = \Big[v_i(x^*)+\sum_{j\neq i}\hat v_j(x^*)\Big] - \max_{x}\sum_{j\neq i}\hat v_j(x)$$

後面那項（別人的最大值）完全不受 $i$ 的申報影響,是個常數;所以 $i$ 想極大化 $u_i$,等價於想極大化 $v_i(x^*)+\sum_{j\neq i}\hat v_j(x^*)$——而這正是機制在第一步做的事。**只要 $i$ 誠實申報 $\hat v_i=v_i$,機制選出的 $x^*$ 就正好是 $i$ 想要的那個。** 謊報只會讓機制去最大化一個「摻了假資訊」的總和,結果不會比誠實時對 $i$ 更好。

（更一般的 **Groves 機制**允許付款公式裡的常數項 $h_i(\hat v_{-i})$ 是任意不依賴 $i$ 自己申報的函數,Clarke pivot rule 只是其中一種選擇——但它額外保證了個人理性:誠實參與者的效用不會是負的。）

# 範例:對應到拍賣/勞動市場的出價-付款

以單一任務、多個投標者的簡化場景為例(對應 [[AgentLance - Decentralized LLM Agent Market]] 的設計):

- 「價值」換成**分配分數** $S_i = \hat p_i - \alpha b_i$(預期成功率減去出價換算的成本)。
- 中標者是分數最高者 $i^*=\arg\max_i S_i$ —— 對應 VCG 的「選最大化總分配分數的結果」(這裡結果空間只是「選哪一個 winner」,同時選中者以外的人分數都算 0,結構等價於單品拍賣)。
- 付款：

$$\mathrm{pay}_{i^*}=\frac{\hat p_{i^*}-S^{\max}_{-i^*}}{\alpha},\qquad S^{\max}_{-i^*}=\max\big(\{0\}\cup\{S_j: j\neq i^*\}\big)$$

把它對照回一般公式:「沒有 $i^*$ 時,其他人(含平台自己保留的 0 分方案)能拿到的最高分數」減去「$i^*$ 在場時,其他人拿到的分數(=0,因為任務只分給一個人)」,再除以 $\alpha$ 換算回金額單位——這就是 Clarke pivot payment 在「單任務、單贏家」這個特例下的具體形式。所以**贏家的付款只由「次佳方案」決定,和自己出的價無關**,誠實出價(把自己的出價設成真實預期成本)才是穩定策略。

# 性質與限制

**優點**
- **顯性策略誘因相容(DSIC)**:誠實申報永遠是(弱)最優策略,不需要去猜測其他人的策略,參與者的決策問題大幅簡化。
- **效率(efficiency)**:只要大家誠實,機制選出的 $x^*$ 就是真正最大化總價值的結果——不會因為某方隱藏或謊報資訊而選錯。
- **個人理性(IR)**:採 Clarke pivot rule 時,誠實參與者的效用 $u_i\ge 0$(前提是價值/效用函數的正規化合理),不會因參與而虧損。

**限制(實務上常被卡住的地方)**
- **預算不平衡**:機制收到的付款總和一般不等於 0——可能有盈餘、也可能出現赤字,設計者常常得自己貼錢或想辦法回收多餘的錢,無法同時滿足「預算平衡 + DSIC + 效率」三者(這是機制設計理論裡的一個經典不可能性結果)。
- **計算成本高**:每個參與者的付款都需要「重新求解一次拿掉他之後的最優分配」——組合式問題(例如多任務、多物品組合)這個最佳化本身就是 NP-hard,VCG 要求對每個 agent 各做一次,成本會迅速膨脹。
- **易受勾結(collusion)影響**:DSIC 只保證單一參與者不偏離誠實有利,若多個參與者串通(例如聯合出低價、或用假身分製造虛假競爭),整體機制的誠實保證會被破壞。
- **假名攻擊(false-name bids)**:在允許自由註冊身分的環境(例如網路上的 agent),一個實體可以偽裝成多個投標者操縱付款結果,VCG 本身不天然防禦這點。

> 直覺:VCG 解決的是「怎麼讓誠實成為划算策略」,但不解決「怎麼算得動」「怎麼收支平衡」「怎麼防串通」——這些是套用 VCG 到真實系統(拍賣網站、任務市場、agent 經濟)時要另外處理的工程/機制設計問題。[[AgentLance - Decentralized LLM Agent Market]] 的消融實驗也驗證了拿掉 VCG 付款(改成 pay-as-bid)確實會讓整體分配品質下降,呼應了上面「不誠實出價會傷害效率」的理論預期。
