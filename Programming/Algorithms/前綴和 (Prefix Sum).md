# Intro

前綴和是一種**預處理**技巧：先花 $O(n)$ 把累積和算好，之後每次**區間和查詢**都只要 $O(1)$。
核心觀念：把「區間問題」轉成「兩個端點相減」。

# 一維前綴和

定義 $P[i]$ 為前 $i$ 個元素的和（$P[0]=0$）：
$$P[i] = a_1 + a_2 + \dots + a_i = P[i-1] + a_i$$

則區間 $[l, r]$ 的和為：
$$\text{sum}(l, r) = P[r] - P[l-1]$$

```cpp
// a 為 1-indexed，a[1..n]
vector<long long> P(n + 1, 0);
for (int i = 1; i <= n; i++)
    P[i] = P[i - 1] + a[i];

// 查詢區間 [l, r] 的和
long long query = P[r] - P[l - 1];
```

> 用 $P[0]=0$ 與 1-indexed 可以避免 `l-1` 越界，是最不容易出錯的寫法。

# 二維前綴和

定義 $P[i][j]$ 為左上角 $(1,1)$ 到 $(i,j)$ 矩形的和：
$$P[i][j] = P[i-1][j] + P[i][j-1] - P[i-1][j-1] + a[i][j]$$

查詢子矩形 $(x_1, y_1)$ 到 $(x_2, y_2)$（容斥原理）：
$$P[x_2][y_2] - P[x_1-1][y_2] - P[x_2][y_1-1] + P[x_1-1][y_1-1]$$

```cpp
// 建表
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        P[i][j] = P[i-1][j] + P[i][j-1] - P[i-1][j-1] + a[i][j];

// 查詢子矩形和
long long query = P[x2][y2] - P[x1-1][y2] - P[x2][y1-1] + P[x1-1][y1-1];
```

# 差分 (Difference Array) — 前綴和的反操作

差分用來處理**多次區間加值、最後才查詢**的情境：區間更新 $O(1)$，最後做一次前綴和還原。

定義 $d[i] = a[i] - a[i-1]$，則對區間 $[l, r]$ 全部加 $v$：

```cpp
d[l]     += v;
d[r + 1] -= v;
// 全部操作做完後，前綴和還原回原陣列
for (int i = 1; i <= n; i++)
    a[i] = a[i - 1] + d[i];
```

二維差分同理（四個角落打標記）：
```cpp
d[x1][y1]     += v;
d[x2+1][y1]   -= v;
d[x1][y2+1]   -= v;
d[x2+1][y2+1] += v;
// 之後做二維前綴和還原
```

# 複雜度比較

| 做法 | 預處理 | 單次區間查詢 | 單次區間更新 |
|------|--------|--------------|--------------|
| 暴力 | — | $O(n)$ | $O(n)$ |
| 前綴和 | $O(n)$ | $O(1)$ | 需重建 $O(n)$ |
| 差分 | $O(n)$ | 需重建 $O(n)$ | $O(1)$ |
| 樹狀數組 / 線段樹 | $O(n)$ | $O(\log n)$ | $O(\log n)$ |

> 前綴和適合**先建好、之後不改、只查詢**；若查詢與更新**交錯**，改用樹狀數組 (BIT) 或線段樹。

# 常見應用 / 題型

- **區間和查詢**：最基本用途。
- **和為 K 的子陣列**：搭配 HashMap 記錄前綴和出現次數，$O(n)$ 找 $P[j] - P[i] = K$。
- **二維子矩形和**：影像、棋盤類題目。
- **模運算 / 整除性**：兩個前綴和對某數取模相同 ⇒ 該段區間和可被整除。
- **差分還原**：區間批次加值（如航班預訂、會議室人數）。

```cpp
// 和為 K 的子陣列數量
unordered_map<long long, int> cnt;
cnt[0] = 1;            // 空前綴
long long pre = 0, ans = 0;
for (int i = 0; i < n; i++) {
    pre += a[i];
    ans += cnt[pre - K]; // 找出有幾個前綴使區間和 = K
    cnt[pre]++;
}
```

# 易錯點

- 邊界：用 1-indexed + $P[0]=0$，查詢才不會 `l-1` 越界。
- 溢位：和可能很大，用 `long long`。
- 差分還原別忘了 `r+1`（二維是四個角）。
